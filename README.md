# Temperature-Monitoring_ParthGupta_202501100700104_B
Case Study -02 
"Temperature Monitoring System"

**Problem Statement :-**
- Build a Python code to display messages according to the temperature received from an assumed IoT system.
- Accept max and min limit temperature.
- Generate random values for temperature at every 2 second interval.
- Compare with the limits to display appropriate value.

**Approach :-**
- first import libraries for time and random no. generation.
- then ask the user for min and max temperature limits.
- now generate a random temperature between 0 to 100.
- compare this temp with limits recieved and print outputs.

**Sample Output :-**

Enter minimum temperature limit: 25
Enter maximum temperature limit: 50

Current Temperature: 89
Alert: Temperature is too high

Current Temperature: 86
Alert: Temperature is too high

Current Temperature: 8
Alert: Temperature is too low
